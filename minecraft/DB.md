A Database of all the Adventure Maps (or adjacent) that I collected.

- Each map is contained in the Saves folder of one of my iterations.
- Where required, additional items (texture packs, shaders, settings, etc...) are also noted. All recommendations will be listed here.
- Every time you want to play a map, you must duplicate the saved ones in the Worlds entry. This is to preserve the original. Unstarted (full) maps are denoted as "ORIGINAL", played maps are denoted as "ITERATION number".
- It is recommended to read the original page of each map before starting for any relevant information.

# Special Versions

- Super Hostile's Caves II, Vexelvania, Sanquine Conquest: Made for Super Hostile Modpack 1.0.97+.
- Super Hostile's Lethamyr has different versions denoted by letters. The map is the same, except spawners and loot are shuffled, and Victory Monuments are at different locations. Letters A, B, C, and D are largely interchangeable. Letter E is a special Easy mode added much later, where hardcore is disabled - intended version in modern day. A letter J also exists - this is a gimmick version made for a youtuber, and is not included in the vault.
