# Mechanoids

# Mechanoids

Mechanoids are dickheads that attack your colony occasionally. They are an all-around upgrade to human raids. You can also control them. Below is the general work-flow on how to become a Mech Overlord.

|                                                              |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |     |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| Obtain a [Mechlink](https://rimworldwiki.com/wiki/Mechlink). | Destroy [Ancient Exostrider Midsection](https://rimworldwiki.com/wiki/Ancient_exostrider_midsection) that is on your starting map. This will yield a Transponder, which - if you decrypt it at the Research bench - will allow you to call down a Mechanoid Ship, where you can obtain a Mechlink if you successfully defeat it. (Destroying the Midsection in itself doesn't summon any mechs, and the Quest given by the decryption of the transponder does not expire, so it should be done as early as possible to avoid losing access to it later.)                                                                                                                                                                                                                               |
|                                                              | Raid an [Ancient Mechanitor Complex](https://rimworldwiki.com/wiki/Quests#Ancient_Mechanitor_Complex), which is the only way to obtain subsequent Mechlinks, and is the only way to start if you abandoned your starting tile.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                              | Once you have a Mechlink, you can use it on a colonist to turn him into a Mechanitor, which can control mechanoids. Use it on your base map to avoid bugs - do not use it inside Pocket Dimension. More information on Mechanitors at the end.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Get Mechanoids                                               | One Mechanoids spawns when you obtain your Mechanitor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

| Other Mechanics                                              | Work Groups: Clicking the Cog icon on the bottom bar will allow you to set up different groups. Clicking the Mechanitor responsible for each group will allow for changing what each group does easily. These are Work, Escort, Recharge, or Dormancy. (Naturally, work types cannot be set, because the type of the Mechanoid dictates that).                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                              | Rip Scanner: Captures the Skills and personality (?) of a pawn, which can be placed in a Mechanoid. This kills the human in the process.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|                                                              | Mech Threats: A Mechanoid raid that a Mechanitor can summon. They all need a certain level of progression (gear or buildings) to be available, and serve as the conclusion of each "chapter" in progression. Diabolus = Comms Console, War Queen = Mechband Antenna, and Mechband Dish = Apocriton. It take them hours to days to arrive.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Mechanitors                                                  | A Pawn is turned into a Mechanitor by the usage of a Mechlink.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|                                                              | How many Mechanoids a Mechanitor can control depends on his bandwidth, which can be increased in the following way: Band Nodes are buildable around the base. Control Sublink, Remote Repairer, Repair Probe, Remote Shielder, and Mech Gestation Processor are implants. Airwire Headset, Control Pack, RA Headset, Bandwidth Pack, Integrator Headset, Mech Lord Armor, Mech Lord Helmet are equipment.                                                                                                                                                                                                                                                                                                                                                                              |
|                                                              | Mechanitors don't have to remain on the map of the Mechanoids in order for them to keep working. (verify, AI information)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Research                                                     | Fabrication: Allows you to shred Mechanoid corpses for parts at Machining Tables.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ->> (Note)                                                   | I listed every unlocked Mechanoid below, as to not clutter the unlocks per research.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|                                                              | Basic Mechtech: Subcore Encoder is the structure where you can make Subcores - Mechanoid brains. The Gestator is where you build (and repair) them. These first few mechs only require steel. Recharger is where they rest. Band Nodes increase bandwidth, buildable without cap, but they use 300W of energy. They will retain attunation if the Mechanitor leaves the map. Airwire Headset and Control Pack are the first two equipment pieces. When ready to move on, summon the Diabolus Mech Threat and defeat it.                                                                                                                                                                                                                                                                |
|                                                              | Standard Mechtech: Unlocks an upgraded version of the Gestator and Recharger. These will not replace the previous utilities - if you want access to all mechs, you will need both versions (there is some overlap). The Subcore Softscanner lets you scan a Pawn and produce a Standard Subcore, which is essential for standard mechs. This process will give your Pawn temporary sickness, but does not harm them in any serious way. New items: Bandwidth Pack, Array Headset, Mechcommander Helmet. (This Pack is a direct upgrade for the previous one. Helmet and Headset occupy the same slot, also exclude tier 1 headset). New Implants: Control Sublink, Mech Gestation Processor, [Overcloak Broadcast](https://steamcommunity.com/sharedfiles/filedetails/?id=3587277884). |
|                                                              | High Mechtech: [Advanced Gestator](https://steamcommunity.com/sharedfiles/filedetails/?id=2884029577) is open. Subcore Ripscanner is unlocked, which works similarly to the Subcore Softscanner, except it's lethal for Pawns - prisoners can be used for this purpose. Mech Booster is a new structure, which will increase Mechanoid workspeed in a small radius. New Item: Integrator Headset. New Implants: Control Sublink (High), Remote Repairer, Remote Shielder, [System Interlink](https://steamcommunity.com/workshop/filedetails/?id=3418853181).                                                                                                                                                                                                                          |

Progression (Draft)

1. Becoming a Mechanitor

   - Acquiring a mechlink
   - Choosing a suitable colonist
   - Mech bandwidth and control

2) Basic Mechtech

   - Research requirements
   - Mech gestator and subcore encoder
   - First mechanoids
   - Basic labor and combat roles

3. Mechanoid Infrastructure

   - Charging and power
   - Repair and resurrection
   - Subcore production
   - Pollution and wastepack management

4. Expanding the Workforce

   - Standard Mechtech and advanced research
   - Large gestator and recharger
   - More specialized mechanoids
   - Increasing bandwidth

5. Advanced Mechtech

   - Mechanoid bosses
   - Acquiring advanced technology
   - High-tier mechanoids
   - Advanced mechanitor upgrades

6. Practical Notes

   - Best mechanoids for each task
   - Resource and power costs
   - Limitations and maintenance
   - Useful combinations with other mods

7. Personal Progression Log

   - Current research
   - Current mechanoid roster
   - Next objectives
   - Lessons learned
