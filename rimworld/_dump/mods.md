If you are not me and you intend to use my lists, keep in mind that depending on the last time I played, they might be outdated, so scan them for game version.

I want to reorganize my mod lists so they are more modular, and everything contained is in the correct category. This is the structure:

- Mandatory Core - mostly fixes, performance (if needed in 1.7), options, settings, tweaks, etc... The vanilla experience, except more convenient.
- Vanilla Plus - any mod that expands upon the vanilla (+ DLCs) experience. New / tweaked vanilla mechanics, reworks of vanilla races, small additions that feel very vanilla-like.
- True Expansions - basically DLC-likes. Any mod that adds new mechanics that (even if they don't feel vanilla) should be used in every playthrough. Key is performance, and that they stay in the background unless interacted with intentionally.
- Optional Expansions - any mod that adds a lot of well-rounded content, but you don't want to always run them either due to concerns about performance, or they change up the flow too much to always have them enabled.
- Factions, Races, Animals - these tend to hit performance, and they are more or less a novelty thing. Include any faction, race, and animal first in the higher-order categories where possible, anything else that is good can be left here.
- Newly Added - a category that includes newly added mods, where they must be tested (for content, performance, bugs, etc...) before they are relocated to another higher-order category.
- Awaiting Update - This should be a file inside this database instead, so that I can comment all of them and list temporary replacements.
